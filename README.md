## About Me

I am a software engineer building AI tools for QA teams. I approach them the way a QA lead would: generated tests must be valid, traceable to their source documents, and dependable when many people run jobs at the same time.

I started in test engineering as an SDET intern, finding vulnerabilities in products. That security background still shapes how I design systems: validate every input, check every model output, and fail clearly.

Currently pursuing a B.Tech in Computer Science and Engineering at ITER, SOA University (CGPA 9.78).
