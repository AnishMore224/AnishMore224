## About

I am a software engineer building **AI tools for QA teams**. I approach them as a QA lead would: generated tests must be valid, traceable to their source documents, and dependable when many people run jobs at the same time.

I began in test engineering as an SDET intern, finding vulnerabilities in products. That security background still shapes how I build: validate every input, verify every model output, and fail clearly.

> *My goal is to specialise in AI engineering and cyber security: building AI systems that are secure, verifiable and dependable in real use.*
